# GBC 彩色外壳

GBC 彩色外壳，提供手机和平板横竖屏布局、独立按钮与方向操作反馈，保留游戏原比例。

## 使用

本版通过 Dash 场景开发入口预览，安装后不会自动应用。使用键盘或手柄操作纯边框版本。包内不包含游戏、BIOS 或核心。

## 包含内容

- 4 个布局：手机、平板横竖屏。
- 按压反馈不改变触摸范围。
