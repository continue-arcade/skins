# GBA 紫晶外壳

紫色 GBA 掌机外壳，提供手机和平板横竖屏布局。按钮按下时轻微缩小、下沉并变暗，松开后回弹；十字键随方向倾斜。游戏画面保留 GBA 的 3:2 比例。

## 使用

这是外壳预览版，可从 Continue 官方卡带源下载安装。当前正式应用尚未提供这张外壳的选择入口，安装后不会自动替换游戏画面；本版通过 Dash 开发入口使用。截图来自真实 mGBA 核心运行 GBA Test Suite 的原生渲染，不包含游戏、BIOS 或核心。

按键包含方向、A/B、L/R、Start/Select 和菜单。按钮反馈不改变命中范围，不等待动画完成才发送输入。
