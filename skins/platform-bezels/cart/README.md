# 机种纯边框集

为掌机、家用机和横竖街机填充宽屏空白，包含十七款无按钮边框，保留游戏比例。

## 使用

本版通过 Dash 场景开发入口预览，安装后不会自动应用。使用键盘或手柄操作纯边框版本。包内不包含游戏、BIOS 或核心。

## 包含内容

- GB：无按钮边框
- GBC：无按钮边框
- GBA：无按钮边框
- NES：无按钮边框
- SNES：无按钮边框
- MD：无按钮边框
- SMS：无按钮边框
- GG：无按钮边框
- PCE：无按钮边框
- PS1：无按钮边框
- N64：无按钮边框
- Saturn：无按钮边框
- 横版街机：无按钮边框
- 竖版街机：无按钮边框
- NGP：无按钮边框
- WS 横屏：无按钮边框
- WS 竖屏：无按钮边框
