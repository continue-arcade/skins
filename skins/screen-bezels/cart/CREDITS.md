# 来源

来源为 Libretro common-overlays 的 GB 4K 与 CRT bezel 素材；CC BY 4.0。原始配置、精确版本与 SHA-256 均已留档，Continue 只转换场景和屏幕窗口。CRT 款为黑色屏幕边缘，适合与独立滤镜搭配；不自带扫描线或曲面滤镜。

https://github.com/libretro/common-overlays
