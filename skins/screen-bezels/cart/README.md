# 简洁屏框集

为经典掌机和横竖屏游戏保留简洁屏框，不显示按钮图案或触摸控件，适合搭配实体手柄游玩。

## 使用

本版通过 Dash 场景开发入口预览，安装后不会自动应用。使用键盘或手柄操作纯边框版本。包内不包含游戏、BIOS 或核心。

## 包含内容

- GB 屏框：只保留上半机身与屏幕边缘。
- 横向 CRT 屏框：适合家用机和横版游戏。
- 纵向 CRT 屏框：适合竖版游戏。
- 三款均不含按钮图案、Button、Dpad 或 Stick；不强制改变游戏比例。
